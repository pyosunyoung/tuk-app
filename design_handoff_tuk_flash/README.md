# Handoff: 툭(Tuk) — 번개 (툭 띄우기 · 받은 번개 · 모임방)

## Overview
"지금 볼래?"를 절친에게 던지는 **번개 기능** 화면입니다. 앱의 핵심 행동입니다.

구현 범위:
1. 번개 발송 — 전체 화면 (11a)
2. 받은 번개 목록 (11b)
3. 모임방 — 대기 / 합류 / 종료 (11c)
4. 진입점 — 홈 상단 받은 번개 배너 (11d)
5. 장소 정하기 시트 + 결과 토스트 (11e)
6. 실시간 처리

선행 문서: `design_handoff_tuk_auth/README.md`, `design_handoff_tuk_presence/README.md`, `design_handoff_tuk_friends/README.md`. 토큰과 컴포넌트는 세 문서와 동일합니다.

## About the Design Files
번들의 HTML은 **디자인 레퍼런스**입니다. **HTML/CSS를 복사해 붙이지 말고, 대상 코드베이스(Flutter)의 기존 위젯과 패턴으로 재구현**하세요. 색·타이포·간격·radius 값만 정확히 가져가면 됩니다.

## Fidelity
**High-fidelity.** 모든 수치가 최종값이며 논리 픽셀(pt)은 Flutter 논리 픽셀과 1:1 대응합니다. 기준 캔버스 iPhone 402 × 874 (상태바 56 / 홈 인디케이터 46은 안전영역).
일러스트·이미지 없음. 모든 그래픽은 도형과 텍스트로만 구성합니다.

### 만료 문구 규칙 (번개 전용)
프레즌스의 "꺼져요"와 달리 번개는 **"끝나요"**를 씁니다.
- 60분 이상: "N시간 M분 뒤 끝나요" (M이 0이면 "N시간 뒤 끝나요")
- 10~59분: "M분 뒤 끝나요"
- 10분 미만: **"곧 끝나요"** — 분·초 카운트다운 금지
- 종료 후: **"끝났어요 · 곧 사라져요"**
- 색은 항상 `#8A857E`. 남은 시간이 적어도 빨강·주황 강조 금지
- "만료됨", "종료", "시간 초과", "마감" 표현 금지

### 예약 시각 표기
- 오늘: "오늘 저녁 8시" / "오늘 오후 3시 30분"
- 내일: "내일 점심 12시"
- 그 이후: "8월 21일 저녁 7시"
- 아침(5~11) · 점심(11~14) · 오후(14~18) · 저녁(18~23) · 밤(23~5)

## 네비게이션 제안

### 받은 번개 진입점: **홈 상단 배너** (아바타 배지와 분리)

**근거**
1. **아바타 배지는 이미 친구 신청이 씁니다.** 같은 자리에 두 종류를 합치면 배지를 봐도 무엇인지 알 수 없고, 하나를 처리해도 배지가 남아 혼란이 생깁니다.
2. **번개는 시간에 민감합니다.** "1시간 12분 뒤 끝나요"인 초대를 아이콘 배지 뒤에 숨기면 놓칩니다. 홈을 열자마자 보이는 카드가 맞습니다.
3. **홈의 정보 위계와 맞습니다.** 홈은 이미 "내 상태 → 친구 상태 → 행동" 순입니다. 받은 번개는 **누가 나를 부른 것**이므로 내 상태보다 앞, 최상단에 옵니다.
4. **배너는 스스로 사라집니다.** 받은 번개가 0건이면 배너가 없어 홈이 원래대로 돌아옵니다. 상시 점유하는 탭이나 아이콘과 다릅니다.

```
홈 (프레즌스)
 ├─ [상단 배너: 받은 번개 N] → 받은 번개 목록 (push)
 │      └─ [합류하기] → 모임방 (replace — 목록으로 되돌아가지 않음)
 │      └─ [모임방 열기] → 모임방 (push)
 ├─ [하단 CTA 툭 띄우기] → 발송 화면 (full-screen modal, 아래에서 위로)
 │      └─ 발송 성공 → 모임방 (replace)
 ├─ 친구 카드 탭 → 미리보기 시트 → [{이름}에게 툭 던지기] → 발송 화면
 │      (파라미터: targetUserIds=[id], prefill activity)
 │      └─ [절친 모두에게 던지기] → 발송 화면 (targetUserIds=[], prefill activity)
 └─ 우상단 아바타 (배지=친구 신청) → 친구 화면
```

- 받은 번개가 1건이면 배너를 탭했을 때 목록을 건너뛰고 바로 그 번개의 상세로 갈 수도 있지만, **하지 마세요.** 건수에 따라 도착지가 달라지면 예측이 어려워집니다. 항상 목록으로 갑니다.
- 진행 중인 내 모임방으로 돌아가는 경로: 받은 번개 목록 상단에 "내가 띄운 번개" 섹션을 두지 말고, **홈 상단 배너에 통합**합니다. 내가 띄운 번개가 살아 있으면 배너 문구가 "내가 띄운 번개 · 술 · 3명 모였어요"가 되고 탭하면 모임방으로 직행합니다. 받은 번개와 동시에 있으면 배너를 두 개 쌓습니다(gap 8, 내 번개가 위).

### 푸시 알림
| 이벤트 | 문구 | 탭 시 |
|---|---|---|
| NEW_FLASH | "민수가 툭 던졌어요 · 술" | 받은 번개 목록 |
| NEW_FLASH (예약분 도착) | "민수가 툭 던졌어요 · 영화" | 받은 번개 목록 |
| MEMBER_JOINED | "지호가 합류했어요" | 해당 모임방 |

- 배너 배지는 **미합류(`myStatus: PENDING`) 건수만** 셉니다. 합류한 번개는 배지에서 제외
- 앱이 포그라운드이고 홈에 있을 때: 푸시 배너를 띄우지 않고 상단 배너를 갱신 + 가벼운 햅틱 하나
- 모임방을 보고 있을 때 MEMBER_JOINED: 토스트 없이 참여자 목록에만 등장

**형식: 전체 화면 (full-screen modal).** 시트가 아닌 이유:

### 2. 받은 번개 목록 (11b)
**목적**: 나를 부른 번개를 훑고 합류한다. 무시는 아무것도 하지 않는 것.

**레이아웃**
- 헤더: ← 36×36 + "받은 번개" 20/600/-0.3 + 개수 20/600 `#FF7A5C` (gap 12 / 개수는 gap 8)
- 스크롤 영역: 좌우 20, 하단 46. 카드 gap 12, 위 margin 12
- 하단 고정 CTA 없음 (행동은 카드 안에 있음)

### 7. 실시간
**전송**: 소켓 또는 서버 푸시. 오프라인이면 FCM. 폴링 대체 시 30초 + 포그라운드 복귀 즉시 1회.

**NEW_FLASH**
- 받은 번개 목록을 보고 있으면: 정렬 규칙에 맞는 위치에 카드 삽입 (240ms ease-out). "NEW" 배지·배경 플래시 없음
- 홈에 있으면: 상단 배너 등장/갱신 + 가벼운 햅틱. 푸시 배너는 띄우지 않음
- 다른 화면이면: 시스템 푸시

**MEMBER_JOINED**
- 해당 모임방을 보고 있으면: 멤버 카드 삽입, 토스트 없음
- 아니면: 토스트(포그라운드) 또는 푸시(백그라운드) "{이름}가 합류했어요"
- 보낸 사람과 기존 합류자 모두에게 전달됩니다

**만료**
- `expiresAt` 도달 시 로컬 타이머로 처리. 서버 재폴링에 의존하지 않습니다
- 받은 번개 목록: 카드 조용히 제거
- 모임방: 종료 스타일로 전환
- 홈 배너: 갱신 또는 제거
- 만료 임박 경고("10분 남았어요")를 만들지 마세요

**백그라운드 복귀**
전체 상태를 다시 받아 교체. 이때는 등장/사라짐 애니메이션을 생략하고 즉시 반영합니다.

**카운트다운**: 화면마다 타이머를 두지 말고 단일 소스에서 1분 tick을 흘려보내고, 리빌드 범위를 만료 문구 텍스트로 한정합니다.

## 반드시 지킬 UX 원칙 (재확인)
1. **거절이 보이지 않는다** — 받은 번개에 거절/무시/나중에 버튼, 스와이프 삭제, 롱프레스 메뉴를 만들지 않습니다. 무시는 아무것도 하지 않는 것이며 보낸 사람에게 어떤 형태로도 전달되지 않습니다. **어느 화면에도** "N명 중 M명", 응답률, 읽음 표시, 무응답자 목록, "아직 안 봄", 대기 중 슬롯을 노출하지 않습니다. 모임방 `members`는 보낸 사람 + 합류자뿐이고, `recipientCount`는 발송 직후 토스트에만 쓰고 모임방에는 노출하지 않습니다. 서버가 비절친을 제외해 수가 줄어도 그 차이를 설명하지 않습니다.
2. **자동 만료** — 번개는 시간이 지나면 사라집니다. "N시간 M분 뒤 끝나요", 임박 시 "곧 끝나요", 종료 후 "끝났어요 · 곧 사라져요". "만료됨", "종료", "시간 초과", "마감" 금지. 남은 시간을 빨강·주황으로 강조하거나 초읽기를 보여주지 않습니다. 만료 임박 경고를 띄우지 않습니다.
3. **무부담** — 발송·합류·장소 설정 근처에 안심 문구를 둡니다. 발송 화면을 닫을 때, 콜을 끌 때, 시트를 닫을 때 확인 다이얼로그를 띄우지 않습니다. 실패도 성공과 같은 톤으로 처리합니다.
4. **닫힌 절친** — 대상은 항상 내 절친뿐입니다. 서버가 절친 관계를 재검증하므로 비절친은 자동 제외됩니다. 전체 검색, 추천, 근처 사람, 친구의 친구, 공개 번개 UI를 만들지 않습니다.

## Implementation Notes
- **HTML/CSS를 복사해 붙이지 말고, Flutter 위젯으로 재구현하세요.**
- 새 컴포넌트를 만들지 말고 기존 것을 재사용합니다: 아바타, 아바타 스택, PillButton(주/보조/48 인라인), 활동 칩, 세그먼트, 프리셋 행, 카드, 섹션 헤더(제목+코랄 개수), 빈 상태 카드, 바텀시트 셸, 토스트.
- 번개 카드와 멤버 카드는 친구 기능의 카드와 같은 컴포넌트 변형입니다 — 테두리 색과 우측 슬롯만 다릅니다.
- 발송 화면의 활동 칩·시간 프리셋은 프레즌스의 "지금 콜 켜기" 시트와 동일한 컴포넌트입니다.
- 모든 텍스트는 Pretendard (400/500/600).
- 일러스트·이미지 에셋 없음. 도형과 텍스트만.
