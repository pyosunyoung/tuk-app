# Handoff: 툭(Tuk) — 프레즌스 (지금 콜 · 지금 한가한 친구)

## Overview
로그인 이후의 **프레즌스 기능** 화면입니다. 사용자는 "지금 콜"을 켜서 자신이 한가함을 절친에게만 알리고, 한가한 친구 목록을 봅니다.

구현 범위:
1. 홈 — 친구 있음 (9a)
2. 홈 — 내 콜 꺼짐 + 친구는 한가함 (9b)
3. 홈 — 한가한 친구 0명, 내 콜은 켜짐 (9c)
4. 콜 켜기 바텀시트 + 켠 직후 피드백 (9d)
5. 친구 카드 탭 → 미리보기 시트 (9e) — **툭 발송 상세는 이 범위 밖**
6. 실시간 등장/사라짐 처리

선행 문서: `design_handoff_tuk_auth/README.md` (스플래시·랜딩·인트로·카카오 로그인·홈 콜드스타트). 토큰과 컴포넌트는 그 문서와 동일합니다.

## About the Design Files
번들의 HTML은 **디자인 레퍼런스**입니다. HTML/CSS를 복사해 붙이지 말고, **대상 코드베이스(Flutter)의 기존 위젯과 패턴으로 재구현**하세요. 색·타이포·간격·radius 값만 정확히 가져가면 됩니다.

## Fidelity
**High-fidelity.** 모든 수치가 최종값입니다. 기준 캔버스 iPhone 402 × 874 pt (상태바 56 / 홈 인디케이터 46은 안전영역).
일러스트·이미지 없음. 모든 그래픽은 도형과 텍스트로만 구성합니다.

### 활동 값 (고정 7종, 이 순서로 표시)
밥 · 술 · 카페 · 산책 · 영화 · 노래방 · 아무거나

### 만료 문구 규칙 (기존과 동일)
- 60분 이상: "N시간 M분 뒤 자동으로 꺼져요"
- 60분 미만: "M분 뒤 자동으로 꺼져요"
- 자정 만료: "자정에 자동으로 꺼져요"
- 1분 단위 갱신. "만료됨", "종료", "실패" 같은 표현 금지.

### 친구 카드의 남은시간 표기 (신규 규칙)
같은 `remainingSeconds`를 쓰지만 **더 짧게** 씁니다. 카드가 조밀하기 때문입니다.
- 60분 이상: "N시간 M분 남음" (M이 0이면 "N시간 남음")
- 10~59분: "M분 남음"
- 10분 미만: **"곧 꺼져요"** — 분 단위 카운트다운을 보여주지 않습니다. 초읽기는 조급함을 만들고 무부담 원칙에 어긋납니다.
- 색은 항상 `#8A857E`. 남은 시간이 적어도 빨강·주황으로 강조하지 않습니다.

**안심 문구**
"무시해도 상대에겐 아무것도 안 보여요" 12/400 `#8A857E` 중앙.

- 콜 카드 본문(토글 제외) 탭 → 콜 켜기 시트를 **수정 모드**로 열기 (현재 활동·시간이 선택된 상태)
- 친구 카드 탭 → 미리보기 시트 (9e)
- 버튼 눌림: scale 0.98 + `#E85D3D`, 120ms
- 당겨서 새로고침 지원. 스피너는 `#FF7A5C`

### 2. 홈 — 내 콜 꺼짐 (9b)
**목적**: 내가 꺼져 있어도 친구 목록은 볼 수 있게 하고, 켜두는 이득을 부담 없이 알린다.

9a와 동일한 골격에서 세 곳만 다릅니다.

**지금 콜 카드 (꺼짐)**
배경 `#FBF7F1` / `1px solid #ECE7DF` / radius 16 / padding 20.
- 8×8 원 `#ECE7DF` + "지금 콜 꺼짐" 20/600/-0.3 **`#8A857E`**
- 들여쓰기 16: "켜두면 한가할 때 친구에게만 보여요" 14/400 `#8A857E`
- 토글 `#ECE7DF`, 노브 좌측

**유도 배너** (리스트 아래, 위 margin 16)
`#FFEAE2` / radius 12 / padding 14 16 / 가로 flex gap 10 — 6×6 원 `#FF7A5C` + "나도 켜두면 친구가 먼저 부를 수 있어요" 14/500 `#E85D3D`.
꺼짐 상태에서만 표시. 탭하면 콜 켜기 시트.

**하단 CTA**
"툭 띄우기" 대신 **"지금 콜 켜기"**. 콜이 꺼진 상태에서는 켜는 것이 첫 행동입니다.
(친구에게 툭을 던지는 것 자체는 콜이 꺼져 있어도 친구 카드 탭으로 가능합니다.)

### 3. 홈 — 한가한 친구 0명 (9c)
**목적**: 아무도 없어도 "잘못된 상태"로 느끼지 않게 한다. 콜이 켜져 있다는 사실 자체를 안심 요소로 쓴다.

- 지금 콜 카드는 켜짐 상태 그대로
- 섹션 헤더 개수는 **`0`** (코랄 유지 — 회색으로 죽이지 않습니다. 0도 정상 상태입니다)
- 빈 상태 카드: `#FFFFFF` / border / radius 16 / padding 32 24 / 세로 중앙 정렬 / gap 12
  - 아바타 자리표시자 3개 (38 원, `#FBF7F1`, `1px dashed #ECE7DF`, -10 겹침)
  - "아직 아무도 안 켰어요" 16/600 `#2B2926` 중앙 (위 margin 4)
  - "켜져 있으니 괜찮아요. 친구가 한가해지면 바로 알려줄게요." 14/400/1.55 `#8A857E` 중앙, max-width 240
- 카드 아래 여백을 `flex:1`로 밀고, 하단에 "먼저 툭 던져두면 친구가 볼 때 뜰 수도 있어요" 12/400 `#8A857E` 중앙
- 하단 CTA "툭 띄우기" 유지 — 아무도 안 켰어도 던져둘 수 있어야 합니다

**금지**: "친구가 없습니다", "0명", 재시도 버튼, 경고 아이콘. 빈 상태를 오류처럼 보이게 하지 마세요.

### 4. 콜 켜기 — 바텀시트 (9d)
**형식 제안: 바텀시트.** 별도 화면이 아닌 이유는 세 가지입니다.
1. 입력이 두 개뿐(활동, 시간)이라 한 화면을 채울 분량이 아닙니다.
2. 브랜드가 "툭 던지듯 가볍게"입니다. 화면 전환은 절차처럼 느껴집니다.
3. 시트 뒤로 홈이 보이면 "이 상태가 바로 저 카드에 반영된다"는 맥락이 유지됩니다.

**레이아웃**
- 딤: `rgba(43,41,38,.28)`, 탭하면 닫힘
- 시트: `#FFFFFF`, radius 24 24 0 0, padding 24 20 40, shadow `0 -4px 24px rgba(43,41,38,.08)`
- 그랩 핸들: 40×4, radius 999, `#ECE7DF`, 가로 중앙, 아래 margin 20
- 제목 "지금 뭐 하고 싶어요?" 20/600/-0.3 `#2B2926`
- 활동 칩 그룹: 위 margin 16, wrap flex gap 8. 칩 padding 12 18, radius 999, 16/500
  - 비선택: `#FBF7F1` / `1px solid #ECE7DF` / `#8A857E`
  - 선택: `#FFEAE2` / `1px solid #FFD4C6` / `#E85D3D`
  - 단일 선택. 기본값은 마지막에 쓴 활동, 없으면 "아무거나"
- "얼마나 열어둘까요?" 14/500 `#8A857E` (위 24, 아래 12)
- 시간 프리셋 4개: 가로 flex gap 8, 각 `flex:1`, padding 12 0, radius 12, 중앙 정렬 16/500. 색은 칩과 동일 규칙
  - **1시간 · 2시간 · 4시간 · 직접**
  - 기본 선택 **2시간**
  - "직접" 탭 → 시트 안에서 30분 단위 휠 피커로 교체 (범위 30분~12시간 = `durationMinutes` 1~720 중 실사용 구간). 확정하면 프리셋 자리에 "3시간 30분"처럼 표시되고 선택 상태가 됩니다
- 주 CTA: 56 pill `#FF7A5C`, 위 margin 24, 라벨은 선택값을 반영 — **"{시간} 동안 콜 켜기"**
- 안심 문구: 12/400 `#8A857E` 중앙, 위 margin 12 — "절친 {N}명에게만 보여요 · {시간} 뒤 자동으로 꺼져요"

**켠 직후 피드백** (9d 오른쪽)
1. 시트가 260ms `cubic-bezier(.32,.72,0,1)`로 내려감
2. 콜 카드가 꺼짐 → 켜짐으로 전환 (배경·점·토글 200ms). 켜진 카드는 3초간 강조: border `#FFD4C6`, shadow `0 4px 16px rgba(255,122,92,.14)` → 이후 기본 border로 복귀
3. 토스트 "지금 콜을 켰어요 · {활동}" 1.8초
4. 하단 CTA가 "지금 콜 켜기" → "툭 띄우기"로 교체 (크로스페이드 160ms)
5. 성공 알림음·햅틱은 가벼운 selection 수준 하나만. 성공 애니메이션(체크마크, 폭죽) 금지

**데이터 매핑**
- 요청: `{ activity: <7종 중 하나>, durationMinutes: <1~720> }`
- 프리셋 → 60 / 120 / 240, "직접" → 피커 값
- 응답으로 받은 `{ available, activity, remainingSeconds }`로 콜 카드를 갱신
- 실패 시: 시트를 닫지 않고 유지, CTA를 원상 복귀, 토스트 "잠시 후 다시 시도해 주세요."

### 5. 친구 카드 탭 → 미리보기 시트 (9e)
**목적**: 카드를 탭했을 때 곧바로 발송되지 않게 하면서, 다음 행동의 경계를 분명히 한다.

**경계 (중요)**
이 시트까지가 프레즌스 범위입니다. 시트의 주 CTA를 누르면 **툭 발송 상세 화면(별도 기능)** 으로 넘어가고, 그 화면의 설계와 실제 발송 처리는 이 문서 밖입니다. 여기서는 **네비게이션과 파라미터 전달만** 구현하세요.
- "{이름}에게 툭 던지기" → 발송 상세로 이동, 파라미터 `{ targetUserId, prefillActivity: friend.activity }`
- "절친 모두에게 던지기" → 발송 상세로 이동, 파라미터 `{ target: 'all', prefillActivity: friend.activity }`

**레이아웃**
- 딤·시트·핸들은 9d와 동일 규격
- 프로필 행: 가로 flex gap 12
  - 아바타 52 원 `#FFEAE2`, 이니셜 20/600 `#E85D3D`
  - 이름 20/600/-0.3 + 활동 칩 (gap 8) / 그 아래 6×6 원 `#3DBE8B` + "지금 가능" 12/500 `#3DBE8B` + "· {남은시간}" 12/400 `#8A857E`
- 주 CTA 56 pill `#FF7A5C` "{이름}에게 툭 던지기" 16/600 흰색 (위 margin 24)
- 보조 52 pill `#FFFFFF` + `1px solid #ECE7DF`, "절친 모두에게 던지기" 16/500 `#8A857E` (위 margin 12)
- 안심 문구 12/400 `#8A857E` 중앙 "무시해도 상대에겐 아무것도 안 보여요" (위 margin 12)

**표시하지 않는 것**: 친구의 최근 활동 이력, 함께 만난 횟수, 응답률, 마지막 접속 시각. 프로필을 성적표로 만들지 않습니다.

### 6. 실시간 변화
**전송 방식**: 소켓 또는 서버 푸시로 프레즌스 이벤트를 수신. 폴링으로 대체할 경우 30초 간격 + 앱 포그라운드 복귀 시 즉시 1회.

**친구가 콜을 켬 (등장)**
- 리스트 **맨 위가 아니라 정렬 규칙에 맞는 위치**에 삽입 (`remainingSeconds` 내림차순이므로 보통 상단)
- 애니메이션: 높이 0 → 실제 높이 + opacity 0 → 1, 240ms ease-out. 배경 플래시나 "NEW" 배지 없음
- 섹션 개수는 같은 프레임에 갱신
- 앱이 포그라운드일 때 별도 토스트를 띄우지 않습니다. 목록에 나타나는 것 자체가 알림입니다

**친구가 끔 · 만료됨 (사라짐)**
- 카드 opacity 1 → 0 + 높이 축소, 200ms ease-in. 사라진 자리를 남기지 않음
- **어떤 문구도 남기지 않습니다.** "민수님이 콜을 종료했습니다" 같은 알림 금지 — 끈 사실이 상대에게 통보되면 부담이 생깁니다
- 미리보기 시트(9e)를 열어둔 상태에서 그 친구가 꺼진 경우: 시트를 강제로 닫지 않고, 주 CTA를 비활성(`#FBF7F1`, 텍스트 `#8A857E`, 탭 불가)으로 바꾸고 그 아래에 "지금은 콜이 꺼졌어요. 그래도 던져두면 볼 수 있어요." 12/400 `#8A857E`를 표시. "절친 모두에게 던지기"는 활성 유지
- 리스트가 0이 되면 빈 상태(9c)로 크로스페이드 200ms

**내 콜 만료**
- `remainingSeconds`가 0에 도달하면 콜 카드가 꺼짐 상태로 전환 (200ms)
- 토스트나 다이얼로그 없음. 하단 CTA만 "지금 콜 켜기"로 교체
- 만료 직전 경고("5분 남았어요") 금지 — 사용자를 재촉하지 않습니다

**백그라운드 복귀**
포그라운드 복귀 시 서버 상태를 다시 받아 전체 리스트를 교체합니다. 이때는 등장/사라짐 애니메이션을 생략하고 즉시 반영(누적 변화가 많아 애니메이션이 산만해짐).

## 반드시 지킬 UX 원칙 (재확인)
1. **거절이 보이지 않는다** — 응답률, "N명 중 M명", 읽음 표시, 무응답자 목록, "아직 답 없음" 같은 표현을 어떤 화면에도 노출하지 않습니다. 가능·합류한 사람만 보여줍니다.
2. **자동 만료** — 콜과 번개는 시간이 지나면 꺼집니다. 항상 "자동으로 꺼져요", "곧 꺼져요"처럼 부담을 덜어주는 문구를 씁니다. "만료됨", "종료", "시간 초과" 금지. 남은 시간을 빨강으로 강조하거나 초읽기를 보여주지 않습니다.
3. **무부담** — 주요 액션 근처에 항상 안심 문구를 둡니다. 콜을 끄거나 시트를 닫을 때 확인 다이얼로그를 띄우지 않습니다.
4. **닫힌 절친** — 탐색, 추천, 근처 사람, 친구의 친구가 등장하는 UI를 만들지 않습니다. 목록에는 내가 등록한 절친만 나옵니다.
