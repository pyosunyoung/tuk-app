# Handoff: 툭(Tuk) — 첫 진입 · 인트로 · 카카오 로그인 · 홈(콜드스타트)

## Overview
"툭"은 5~10명 닫힌 절친 그룹 안에서 "지금 볼래?"를 부담 없이 던지는 즉흥 만남 앱입니다.
이 번들은 **앱 첫 실행부터 로그인 직후 홈 화면까지**의 UI를 다룹니다.

구현 범위 (플로우 순서):
1. 스플래시 (7a-1)
2. 랜딩 = 첫 진입 화면 (7a-2)
3. 인트로 5컷 (6b) — 랜딩에서 "둘러보기"를 누른 사용자만 진입, 언제든 건너뛰기 가능
4. 카카오 소셜 로그인 (랜딩·인트로 마지막 컷의 노란 버튼)
5. 로그인 직후 홈 — 친구 0명 콜드스타트 (1b)

친구가 있는 홈(1a)은 이번 범위 밖이지만 같은 파일에 들어 있어 참고할 수 있습니다.

## About the Design Files
번들에 든 HTML 파일은 **디자인 레퍼런스**입니다. 의도한 모양과 동작을 보여주는 프로토타입이며, 그대로 가져다 쓰는 프로덕션 코드가 아닙니다.
목표는 이 화면들을 **대상 코드베이스(Flutter)의 기존 패턴과 위젯으로 다시 만드는 것**입니다. HTML/CSS를 옮겨 붙이지 마세요. 색·간격·타이포 값만 정확히 가져가면 됩니다.

## Fidelity
**High-fidelity.** 색상 hex, 폰트 크기·굵기, 간격, 모서리 반경이 모두 최종값입니다. 픽셀 단위로 재현하세요.
단, 일러스트/이미지는 없습니다 — 모든 그래픽은 도형과 텍스트로만 구성되어 있습니다.

기준 캔버스: iPhone 402 × 874 pt. 상태바 56, 홈 인디케이터 46은 프레임이 차지합니다(안전영역).

## 로고 (앱 아이콘 · 워드마크)

코랄 정사각 타일 안에 흰색 '툭'을 **왼쪽 아래 정렬**하고, 그 위로 던지는 궤적을 얹습니다.

구성 (120pt 타일 기준, viewBox 0 0 120 120):
- 타일: 120×120, radius 28, `#FF7A5C`, `overflow: hidden`
- 궤적 굵은 획: path `M28 44c22-16 46-18 66-8`, stroke `#FFFFFF` opacity .5, width 7, round cap
- 궤적 흐린 획: path `M40 36c18-8 36-8 52-2`, stroke `#FFFFFF` opacity .22, width 3, round cap
- 끝점: circle cx 96 cy 36 r 8, fill `#FFC24B`
- 글자: '툭' 52pt / 600 / 자간 -3 / line-height .9, 좌하단 padding 14 16

축소 규칙: 타일이 작아질수록 stroke와 점을 **상대적으로 굵게** 키웁니다(viewBox 좌표 기준).
- 80pt: stroke 8 / 점 r 8.5
- 56pt: stroke 9 / 점 r 9.5 (흐린 획 생략)
- 40pt: stroke 10 / 점 r 10 (흐린 획 생략)
- 24pt 이하: stroke 12~14 / 점 r 11~12 (흐린 획 생략)

밝은 배경 위 변형: 타일 `#FFEAE2`, 글자·굵은 획 `#FF7A5C`(획 opacity .45), 점은 그대로 `#FFC24B`.
스플래시 변형: 화면 전체 `#FF7A5C`, 타일 `rgba(255,255,255,.14)`.

## Interactions & Behavior

### 네비게이션
```
스플래시 (자동 1s)
  └→ 랜딩
        ├─ [카카오로 3초 만에 시작] → 카카오 인증 → (신규) 홈 콜드스타트 / (기존) 홈
        └─ [30초만 둘러보기] → 인트로 컷1
                                 ├─ [다음] ×4 → 컷5 → [카카오로 시작하기] → 카카오 인증 → 홈
                                 └─ [건너뛰기] → 랜딩
```
- 인트로는 좌우 스와이프로도 이동. 마지막 컷에서 오른쪽 스와이프는 아무 동작 없음
- 인트로 재방문 가능: 랜딩의 둘러보기는 로그인 전이면 언제든 진입
- 로그인 성공 후에는 스플래시 → 홈으로 직행 (랜딩·인트로 건너뜀). 인트로 시청 여부를 로컬에 저장할 필요는 없음 — 로그인 상태만 보면 됨

### 카카오 로그인
- 버튼 탭 → 카카오 SDK 인증(앱 스킴 우선, 미설치 시 웹뷰)
- 로딩 중: 버튼 텍스트 자리에 스피너, 버튼 비활성(opacity .6), 배경색 유지
- 취소: 아무 화면 전환 없이 원래 화면 유지, 에러 토스트 없음(사용자가 의도적으로 취소한 경우)

- 첫 로그인 성공 → 홈 콜드스타트(1b)

### 모션
- 화면 전환: 인트로 컷 간 가로 슬라이드 260ms, `cubic-bezier(.32,.72,0,1)`
- 인디케이터: 활성 점의 폭 6→20 변화를 200ms로
- 버튼 눌림: scale 0.98 + 배경 `#E85D3D`, 120ms
- 토글: 노브 이동 + 트랙 색 200ms
- 과한 바운스·튐 금지. 무드는 "포근하고 가볍게"

## 반드시 지켜야 할 UX 원칙
1. **거절이 보이지 않는다** — 응답률, "N명 중 M명", 읽음 표시, 무응답자 목록을 어떤 화면에서도 노출하지 않습니다. 합류한 사람만 보여줍니다.
2. **자동 만료** — 상태와 번개는 시간이 지나면 꺼집니다. 만료는 항상 "자동으로 꺼져요"처럼 부담을 덜어주는 문구로 씁니다. "만료됨", "종료" 같은 딱딱한 표현을 쓰지 않습니다.
3. **무부담** — 주요 액션 근처에 항상 안심 문구를 둡니다.
4. **닫힌 절친** — 낯선 사람이 등장하는 UI(탐색, 추천, 근처 사람)를 만들지 않습니다.
